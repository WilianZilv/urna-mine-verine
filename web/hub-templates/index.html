Quick start

1. copie a pasta do template (canvas2d/ ou threejs/)
2. troque o id/nome (data-portal-id, PORTAL_ID, título)
3. publique numa hospedagem HTTPS grátis (Cloudflare Pages, Netlify, GitHub Pages de usuário)
4. sirva /.well-known/urna-portal.json com o challenge do registro
5. registre seguindo o /hub.txt (comandos prontos no gerador)

Ou mande pro teu agente de IA: Lê https://urna-mine-verine.wilianzilv.workers.dev/hub.txt e coloca meu jogo no hub
